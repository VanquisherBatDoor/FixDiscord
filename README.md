>
> Добавьте каталог zapret в исключения либо отключите обнаружение PUA (потенциально нежелательных приложений). Если вы уверенно настраиваете исключения, добавьте исключение; при сомнениях отключите детектирование PUA.

## ⚙️ Использование

1. Сначала включите Secure DNS.
   * В Chrome включите "Использовать безопасный DNS" и выберите DNS-поставщика, отличного от "Поставщика по умолчанию".
   * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
   * В Windows 11 Secure DNS можно включить непосредственно в настройках ОС. [Инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот вариант рекомендуется.
   * На роутерах Keenetic включите параметр "Транзит запросов". При его отключении Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/VanquisherBatDoor/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг можно пропустить.

4. Распакуйте архив в путь без кириллицы и специальных символов.

5. Запустите нужный файл.
   * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
   * Для автозапуска выберите **`service.bat`** -> `Install Service` -> подходящую стратегию.

## ℹ️ Кратко о файлах

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому пробуйте стратегии **ALT**, **FAKE** и другие, пока не найдёте подходящую.

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** добавляет выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** удаляет стратегию и WinDivert из служб.
  - **`Check Status`** показывает состояние обхода, автозапущенной стратегии и WinDivert.
  - **`Game Filter`** переключает обход для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  После изменения режима стратегию нужно перезапустить.  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** управляет обходом сервисов из `ipset-all.txt`.  
  Это помогает при проверке ресурса, который без zapret работает, а с ним нет.  
  Возможные статусы:
    - `none` — IP-адреса не проверяются
    - `loaded` — проверяется наличие IP в списке
    - `any` — под фильтр попадает любой IP
  - **`Auto-Update Check`** включает или отключает автоматический поиск обновлений.
  - **`Replace active fakes`** заменяет выбранный активный fake другим файлом из `bin`.
  - **`Update IPSet List`** загружает актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** обновляет hosts <ins>для восстановления веб-версии Telegram и подключения Discord к голосовому чату.</ins>
  - **`Check for Updates`** вручную проверяет наличие обновлений.
  - **`Run Diagnostics`** ищет распространённые причины неисправности zapret.  
  В конце можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапной остановки работы.
  - **`Run Tests`** проверяет стратегии:
    - `Standard tests` использует сайты из `utils/targets.txt`.
    - `DPI checkers` проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и проблемы

### После запуска `general*` ничего не видно

После запуска стратегии отдельным bat-файлом, а не через service, процесс обхода winws.exe должен появиться в панели задач. Если этого не произошло, см. [#522](https://github.com/VanquisherBatDoor/zapret-discord-youtube/issues/522).

### Ни одна стратегия не работает

Откройте командную строку от имени администратора и выполните команды по очереди:

`netsh winsock reset`

`netsh int ip reset all`

`netsh winhttp reset proxy`

`ipconfig /flushdns`

После этого перезагрузите компьютер.

### Не открывается Telegram в браузере

В **`service.bat`** выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:

- скопируйте весь текст из открывшегося блокнота;
- откройте файл `hosts` в появившейся папке текстовым редактором от имени администратора;
- добавьте скопированное в конец файла или замените ранее добавленный аналогичный блок;
- сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что файл действительно сохранился.

#### Работа не гарантируется. При отсутствии результата используйте [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/VanquisherBatDoor/tg-ws-proxy) или публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии могут устаревать и переставать работать.**
> Даже рабочая стратегия со временем может быть обнаружена и заблокирована.
> В репозитории есть много вариантов обхода. Если ни один не подходит, создайте новый на основе существующей стратегии и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` откройте `Run Diagnostics` и проверьте ошибки.
- Убедитесь, что адрес ресурса присутствует в списке доменов или IP.
- Проверьте другие варианты, включая **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- Дополнительная информация: [#765](https://github.com/VanquisherBatDoor/zapret-discord-youtube/issues/765).

### Как полностью обновить или переустановить проект?

- Сохраните добавленные вами ресурсы и данные.
- Перезапустите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; если найдены ошибки, устраните их, затем в конце выберите Y.
- Удалите каталог zapret.
- Скачайте свежую версию со [страницы релизов](https://github.com/VanquisherBatDoor/zapret-discord-youtube/releases), архив вида `zapret-discord-youtube-...`.
- Откройте свойства архива правой кнопкой мыши. При наличии флажка разблокировки установите его, нажмите «Применить» и «ОК».
- Распакуйте архив в новый каталог в корне диска без пробелов и специальных символов.
- По очереди проверьте разные `general`-скрипты. Если ресурс недоступен, закройте программу через значок замка в панели задач и выберите другую стратегию.
- После нахождения рабочего варианта установите его в автозапуск через `service.bat` -> `Install Service`.

### Игра или приложение не работает при включённом zapret

Проверьте в `service.bat`, что `Game Filter` имеет статус **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

Инструкция находится [здесь](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

### В Windows 7 нужна цифровая подпись драйвера WinDivert

Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остался среди служб

1. В командной строке Windows, открытой через Win+R и `cmd`, найдите имя службы:

```cmd
driverquery | find "Divert"
```

2. Затем остановите и удалите службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8F-использование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если раньше всё работало, протестируйте остальные стратегии.
- Дополнительные сведения: [#251](https://github.com/VanquisherBatDoor/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8F-использование).
- Сначала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- Проверьте, заработало ли приложение после очистки.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, её можно использовать.
- Если браузер также не подключается, последовательно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. [#252](https://github.com/VanquisherBatDoor/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/VanquisherBatDoor/tg-ws-proxy).
- Также можно использовать бесплатные MTProto-прокси из интернета.

### Не запускаются игры

Игры используют разные схемы подключения, поэтому проверить и исправить каждую невозможно.

Обычно помогает следующий порядок:

- обновите ipset через `service.bat` и включите `Game Filter`;
- если результата нет, дополнительно включите `ipset any`.

Учтите: режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса игры и добавьте их в `ipset-all.txt`.

Если это не решило проблему, создайте обсуждение в [Discussions](https://github.com/VanquisherBatDoor/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Проблема не описана

Сообщите о ней [здесь](https://github.com/VanquisherBatDoor/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Расширить список обхода можно через следующие файлы:

- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети для исключения.

Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
